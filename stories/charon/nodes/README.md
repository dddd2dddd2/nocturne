# 简化模型映射说明

《卡戎回声》的 Markdown 节点图被压缩进引擎的固定变量模式，用于自动化可达性审计。
拓扑（节点/连线/条件/结局）忠实保留；变量做如下映射：

| 引擎变量 | 含义（简化模型） | 原设计对应 |
|---|---|---|
| `sanity` 0-100 | 理智值 | `[SAN]` |
| `bond` 0-100 | 真相派绑定度（0=未绑定/离心，高=信任查真相派；回地球派以低 bond ＋ key 表达） | 多 NPC 信任的聚合 |
| `clue_a` 0-40 | 表层证据（密室/裴延行程空白/官方尸检） | `[线索_…]` |
| `clue_b` 0-40 | 深层指纹（0.7秒空隙/修复痕/非周期脉冲） | 三线索 |
| `clue_c` 0-40 | 假死/身份/种子类线索 | `[线索_假死迹象]` 等 |
| `key` bool | 逃生舱密钥 | 白烬背叛线 |
| `CLUE`=a+b+c | 洞察 | `[洞察]` |

## 明确不建模的轴（本次审计范围外）

- `[NORA]`：净舱结局改用「SAN=0 或 bond 崩溃（bond<0 / ≤-15）」代理。
- `[倒计时]`：时间即代价的消耗不建模（属资源轴，非拓扑轴）。
- `[零号·身份觉醒]`：用显式 clue 门槛代理（End_7 需 CLUE≥60）。

## 叙事变体与旗标（按剧情分支切换正文）

默认正文是 `prose/<节点ID>.md`；同一节点可提供**按旗标切换的变体**，
写入 `prose/<节点ID>.variants.md`，用 `<!-- flags: 名=值, ... -->` 切块：

```
<!-- flags: rescue_shen=true -->
（该分支下的完整节点正文）
```

- 引擎 `render` 时取第一个旗标条件满足的变体，否则用默认正文。
- 旗标由选项的 `flags` 置位（单调，一旦置位不再清除），如 2_1「救沈棠」置 `rescue_shen`。
- 旗标同时可作选项/变体的 `condition.flags` 条件（`{名: true|false}`）。
- 目前使用的旗标：`rescue_shen`（救沈棠 → 沈棠活/童野死；未置 → 沈棠死/童野活），
  驱动 2_6 / 3_1 / 3_7 的角色在场与死亡结算文本。

## 名词表（正文高亮 + 档案解密）

`terms.md` 是名词表的唯一手改处（改完跑 `python generate_nodes.py`）：

- 每个词条：`词条 | 首次出现 | 释义 | 关联`；分类由 `##` 小节标题决定，配色见文首「分类配色」表。
- **关联**列填相关词条名（`、`分隔），按名互指、双向生效：A 列了 B，B 也能找到 A。
  人物图谱选中角色时，侧栏会展示其本人词条 + 关联词条（含未解密 ？？？ 条目）。
- **首次出现**填节点 ID，作为未录入条目的去向提示（首次见于「X」）；实际解密按**读到文本**触发：
  玩家读到的正文段落（含变体分支的渲染文本，记录在 `Session.read`）中出现该词条即录入，
  未解密显示 ？？？；留空或 `—` 表示始终公开。普通阅读在节点渲染时整段标记，
  幻灯片模式逐段上报；旧存档打开时按历史节点回填已读。
- 正文渲染时，命中词条按分类配色高亮、悬停显示释义（`splitTermSegments`，最长词条优先，
  如「回声信号」优先于「回声」）。
- 生成器会校验：词条在 prose 中必须真实出现、不得重复、firstSeen 节点必须存在；
  若 firstSeen 节点正文不含该词条会给出警告。
- 产物：`terms.data.ts`（story.ts 导入）与 `docs/名词表/名词表.md`（自动同步）。

## 引擎内置规则（沿用）

- SAN=0 → 立即进入 `Node_End_4`（净舱/团灭）。
- SAN<30 → 强制进入 `Node_3_3`（SAN 濒危·回声幻觉），除非目标是结局或 3_3/3_4。
