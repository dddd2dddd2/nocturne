# 简化模型映射说明

《卡戎回声》的 Markdown 节点图被压缩进引擎的固定变量模式，用于自动化可达性审计。
拓扑（节点/连线/条件/结局）忠实保留；变量做如下映射：

| 引擎变量 | 含义（简化模型） | 原设计对应 |
|---|---|---|
| `sanity` 0-100 | 理智值 | `[SAN]` |
| `bond` 0-100 | 阵营倾向：+ 查真相派（纪岚/童野/陈戍），- 回地球派（白烬/裴延） | 多 NPC 信任的聚合 |
| `clue_a` 0-40 | 表层证据（密室/裴延行程空白/官方尸检） | `[线索_…]` |
| `clue_b` 0-40 | 深层指纹（0.7秒空隙/修复痕/非周期脉冲） | 三线索 |
| `clue_c` 0-40 | 假死/身份/种子类线索 | `[线索_假死迹象]` 等 |
| `key` bool | 逃生舱密钥 | 白烬背叛线 |
| `CLUE`=a+b+c | 洞察 | `[洞察]` |

## 明确不建模的轴（本次审计范围外）

- `[NORA]`：净舱结局改用「SAN=0 或 bond 崩溃（bond<0 / ≤-15）」代理。
- `[倒计时]`：时间即代价的消耗不建模（属资源轴，非拓扑轴）。
- `[零号·身份觉醒]`：用显式 clue 门槛代理（End_7 需 CLUE≥60）。

## 引擎内置规则（沿用）

- SAN=0 → 立即进入 `Node_End_4`（净舱/团灭）。
- SAN<30 → 强制进入 `Node_3_3`（SAN 濒危·回声幻觉），除非目标是结局或 3_3/3_4。
