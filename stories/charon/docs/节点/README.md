
## 变量图例（全篇统一）

**数值变量**：
- `[洞察]` 0–100 —— 逼近隐藏真相的程度
- `[SAN]` 0–100 —— 理智值，过低触发幻觉/死亡
- `[倒计时]` 72h 递减 —— 生存资源
- `[NORA]` 0–100 —— AI 评估/权限

**人物信任**（-100～100）：`[信任_纪岚]` `[信任_沈棠]` `[信任_童野]` `[信任_裴延]` `[信任_陈戍]` `[信任_白烬]`

**线索 flag**：`[线索_密室结论]` `[线索_领药记录]` `[线索_官方尸检]` `[线索_氧气缺口]` `[线索_0.7秒空隙]` `[线索_修复痕]` `[线索_假死迹象]` `[线索_非周期脉冲]` `[线索_裴延行程空白]` `[线索_逃生舱疑点]` `[线索_风暴低语]` `[线索_后门权限码]` `[线索_证据链完整]`

**隐藏变量**（不显示给玩家）：`[零号·身份觉醒]`

## 节点分类标签

- 【主线】—— 推进剧情的必经路径
- 【深度探索】—— 通向隐藏真相的支线
- 【支线】—— 可跳过但影响变量
- 【坏结局】—— 过早死亡/失败
- 【伪结局】—— 信息不足导致的误导结局

## 初始值（配合质检报告 F1 修复）

```
[洞察]=0  [SAN]=100  [倒计时]=72h  [NORA]=10（审计员自带基础授权）  全员信任=0
```
