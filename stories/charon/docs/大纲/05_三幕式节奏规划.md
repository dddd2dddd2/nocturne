# 五、故事三幕式节奏规划

## 第一幕 · 起因（Day 1，前 24 小时）

- 建立封闭舞台与角色群像；
- 林溯"死"于密室；
- NORA 启动封存与双倒计时；
- 玩家学会五个变量的运作机制。

**派系初现**：

- "回地球派"：裴延、白烬；
- "查真相派"：纪岚、陈戍；
- 童野中立；
- 沈棠已濒临失控。

> 本幕悬念：**所有人的证词都在说谎，只是说谎的理由各不相同。**

## 第二幕 · 激化（Day 2，24–48 小时）

- 表面证据链成型，稳稳指向裴延；
- 第二次信号风暴制造二次危机；
- **一名关键 NPC 死亡——死的是谁、是否死，由玩家第一幕的选择决定。**

### 网状叙事示例

- 你若把"密钥卡日志"交给沈棠，她夜里会独自去通讯舱核实；若她当时 SAN值 < 30 且你曾冷落她，她会被回声彻底覆盖。
- 若你隐瞒证据，裴延会销毁物证，但欠你人情，终局成为你的关键票。

- 派系公开撕裂，出现 **"投票处决"机制**；
- 玩家首次触碰"证据过于完美"的矛盾。

## 第三幕 · 爆发与结局收束（Day 3，最后 24 小时 + 终局）

- 倒计时见底，裁决临近，全员进入**囚徒困境式摊牌投票**（合作授权 vs 背叛指认的收益矩阵）；
- 玩家面临岔路：**指认裴延（表面真相线）还是质疑真相（深层线）**；
- 深层线揭晓：林溯假死、NORA 合谋、回声体现形、零号真实身份；
- 终局由五个变量组合 + 身份觉醒值通向多结局。

## 多层结局示例

| 结局 | 走向 |
|---|---|
| **名侦探结局（伪HE）** | 指认裴延 → 裁决执行 → 看似圆满，但回声体未被找出，NORA 在"成功"后静默接管全站——细思极恐 |
| **真相揭示 · 全员存活** | 看穿第二层，在摊牌中逼回声体自曝，救下最多人 |
| **惨胜 / 牺牲** | 为保存活率牺牲自己或关键 NPC |
| **全灭 · 净舱** | 洞察不足 + 信任崩溃 + NORA 评估失控 |
| **玩家即回声体** | 揭晓零号才是被覆盖者，最终抉择 = 自我了断 / 向全站坦白 / 让 NORA 上传自己完成"文明存续" |
| **与AI交易 / 第三势力** | 选择相信 NORA 对抗林溯——林溯的"救世"也可能是另一种控制 |

> 核心：**三个聪明人互相对弈，玩家决定谁赢。**
