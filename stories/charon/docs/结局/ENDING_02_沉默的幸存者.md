# ENDING_02 · 沉默的幸存者（Good/Survival End）

- **结局编号与代号**：`ENDING_02: 沉默的幸存者`
- **结局类型**：Good/Survival End（幸存结局）
- **达成变量判定公式**：
  - 倒计时内达成生存解（`推进器重启` 或 `裁决结案`）
  - `[洞察] < 40`
  - 未集齐三深层线索（0.7秒空隙 / 修复痕 / 假死迹象）
  - `[存活NPC] ≥ 4` 且 `[玩家存活]`
- **终局剧情概要与尾声后日谈**：
  玩家始终站在"保生存"一侧：联合白烬、裴延重启推进器，把林溯之死当成普通凶案草草指认了替罪羊。站上的人活了下来，返航回地球。零号升职，生活归于平静。但夜深人静时，他总会听到一段不该存在的脉冲——他比谁都清楚，那个回声体就坐在返航的舱里，坐在他身边。尾声：多年后，听证会上被问起卡戎站真相，他签下保密协议，说："那里只是一场普通事故。"
- **本结局揭示的世界观碎屑**：
  公司的"意识上传复活技术"确实存在——但复活回来的究竟是不是"本人"，从来没有人敢追问。
