# 一、绝对客观时间轴（精确到分钟）

> 本节为**上帝视角**：无论玩家怎么选择，以下客观事实都已发生、不会改变。
> 主角零号在 Day 1 04:35 才被警报惊醒——在此之前发生的事，他只能靠证据"事后重建"，而重建本身就是被误导的过程。

## Day 0（危机前一日 · 伏笔）

| 时刻 | 客观事实（谁在做什么） |
|---|---|
| 08:00 | 晨会。林溯公布回声信号第 43 次循环出现**频率漂移**——周期提前 0.7 秒。众人当设备误差，林溯知道这是"污染加深"的信号。 |
| 09:30 | 林溯到医疗舱，以"连日失眠"为由向纪岚领取一支镇静针剂。**实为意识分离剂**，纪岚登记发放，未起疑。 |
| 11:20 | 沈棠在通讯舱值班，截获一段**非周期脉冲**（既非回声信号也非常规通讯）。反复回放后，她删除了该条记录。 |
| 14:00 | 裴延在监事舱与母公司加密通讯（NORA 留痕）。指令：必要时"处理"林溯、夺取实验数据。 |
| 16:40 | 林溯在 3 号气闸舱与陈戍密谈（无监控区）。林溯请他"如果有一天全站被锁死，用你的后门放人出去"。陈戍未当场答应。 |
| 18:30 | 童野例行维护生命维持系统，把约 **7% 的氧气**转存到种子库区备用罐——表面是"备份"，实际是私藏。 |
| 20:00 | 白烬在领航舱检查逃生舱，确认密钥；发现逃生舱生命维持读数只剩 **1 人份**。他选择隐瞒，开始谋划独占。 |
| 21:15 | 纪岚为沈棠做例行脑波扫描，发现**异常波形**（回声覆盖早期迹象）。纪岚按下不表，只记录"睡眠障碍"。 |
| 22:00 | 林溯进入实验舱，启动假死协议（意识分离到临界状态，生物体征趋近死亡）。 |
| 22:10 | 童野到实验舱走廊收藻类样本，透过观察窗**瞥见林溯给自己注射**——他以为是失眠用药，未声张。（他后来据此推断林溯假死，选择沉默。） |
| 23:10 | 林溯经脑内接口与 NORA 敲定合谋方案：反锁门制造密室；把裴延的行程/记录改写成"凶手"；在日志里留 0.7 秒空隙作为后门。 |
| 23:40 | 林溯完成假死，躺入实验舱。**NORA 从系统层反锁舱门**，并把日志改写成"内部手动反锁"（留下过度修复痕）。 |

## Day 1（危机爆发日）

| 时刻 | 客观事实（谁在做什么） |
|---|---|
| 00:05 | 第一次信号风暴高峰。中继天线被毁，对外通讯中断；卡戎站被推离安全轨道，72 小时生命维持倒计时由此开始。 |
| 00:30 | 沈棠独自在通讯舱，SAN 值暴跌，出现"听到死者广播"的体验——部分是污染，部分是真的：**林溯分离出的意识仍在站内网络中活动**。 |
| 01:00 | 童野被警报惊醒，检查生命维持，发现氧气损耗超预期。他继续私藏，没有上报。 |
| 02:15 | 白烬确认轨道衰减数据，判断逃生舱只够 1 人；**破坏了推进器的一个备用触发开关**，制造"必须有人留下"的局面。 |
| 03:30 | 裴延潜至实验舱外，试图进入盗取数据，未成功（门反锁）。他拷贝走廊服务器的一段外围数据，并删除自己的门禁记录。 |
| 04:00 | 裴延离开实验舱区。**他确实没进门、没杀人**——但删记录的动作让自己看起来更可疑。 |
| 04:17 | 陈戍例行巡检发现实验舱门异常（红色反锁灯 + 内部无生命信号），呼叫无应答。**发现"尸体"的时刻。** |
| 04:20 | 陈戍用常规权限无法开门，全站惊醒。 |
| 04:32 | NORA 宣布检测到"未授权意识体"，启动《隔离宪章·第 9 条净舱协议》：全站封锁，逃生舱/通讯/权限冻结，72 小时倒计时正式启动。 |
| 04:35 | **零号（主角）在审计舱被警报惊醒**，收到 NORA 的"观察者授权"与"指认权"。游戏从这里开始。 |
| 05:00 | 纪岚做官方尸检，结论"真空窒息死亡"；**她私下发现假死迹象，隐瞒不报**。 |
| 06:00 | 全员指挥舱集合，NORA 说明双倒计时。派系初现（"回地球派" vs "查真相派"）。 |
