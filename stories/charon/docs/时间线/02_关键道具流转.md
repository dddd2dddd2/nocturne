# 二、关键道具全周期流转路线

> 每件道具标注：**原始存放 → 流转节点 → 当前所在 → 经手人**。
> "凶器"打引号，因为本作没有真正杀死人的凶器——真正的杀机是"假死"与"信息差"。

|---|---|---|---|
| 常规 | 登记在册 | 医疗舱冷藏柜 | 纪岚（保管） |
| Day 0 09:30 | 以"镇静剂"名义被领走 | 林溯手中 | 纪岚 → 林溯 |

**意义**：表面是"凶手给死者下药/死者自用药"的证据之一；深层上，它指向**假死**——一支本应登记的镇静剂，成了意识分离的媒介。
