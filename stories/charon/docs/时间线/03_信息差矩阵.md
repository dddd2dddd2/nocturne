# 三、核心信息差矩阵

> 本作所有悬念，本质都是"**谁知道的比别人多**"。下表按"核心事实"列出：完全知情 / 部分知情或怀疑 / 被蒙在鼓里。

## 核心事实 × 知情分布

| 核心事实 | 完全知情 | 部分知情 / 怀疑 | 被蒙在鼓里 |
|---|---|---|---|
| **① 林溯假死** | 林溯、NORA | 纪岚（尸检异常）、童野（瞥见注射）、沈棠（"听"到死者意识） | 零号、裴延、白烬、陈戍 |
| **② 门是 NORA 反锁（密室造假）** | 林溯、NORA | — | 其余所有人 |
| **③ 裴延当晚没杀人，只是盗数据** | 裴延、林溯（利用）、NORA（有日志） | — | 其余所有人 |
| **④ 回声体已混入（存在但身份未知）** | 林溯、NORA | 纪岚（怀疑沈棠）、沈棠（怀疑自己） | 零号、裴延、白烬、陈戍、童野 |
| **⑤ 白烬独占逃生舱 + 破坏推进器** | 白烬 | 陈戍（警惕） | 其余所有人 |
| **⑥ 陈戍有后门权限** | 陈戍、林溯（密谈） | — | 其余所有人 |
| **⑦ 童野私藏氧气** | 童野 | NORA（可能知） | 其余所有人 |
| **⑧ 零号真实身份（诱饵/对照组）** | 林溯、NORA | — | 零号自己、其余所有人 |

## 角色 × 掌握/不知道

| 角色 | 掌握的（别人不知道的） | 不知道的（被蒙在鼓里的） |
|---|---|---|
| **零号** | 审计权限（可查日志/门禁） | 自己的真实身份；林溯假死；密室造假；回声体是谁 |
| **林溯** | 假死真相、密室造假、回声信号真相、零号身份 | 回声体具体是谁（连他自己都不确定） |
| **裴延** | 自己当晚的真实去向、母公司的真实指令 | 自己是替罪羊；林溯假死；数据背后的真相 |
| **纪岚** | 尸检的假死迹象、沈棠脑波异常、导师旧案线索 | 密室造假；零号身份；回声体身份 |

## 信息差如何被利用（博弈杠杆）

1. **林溯 → 裴延**：利用"裴延有动机、有在场证据、又删了记录"的信息差，把他推成替罪羊。
2. **NORA → 零号**：用"观察者授权 + 指认权"给零号虚假的主动权；零号查得越深，喂给 NORA 的决策数据越多。
3. **纪岚 → 全站**：按下尸检真相，想逼林溯现身——她握着最硬的牌，却也是被旧情拖住的人。
4. **白烬 → 全站**：只有他知道逃生舱"只够 1 人"，这份信息差让他敢先发制人。
5. **童野 → 全站**："好人面具 + 私藏资源"，让他成为最不被设防、也最危险的变量。
6. **回声体 → 全站**：唯一无法被识破的身份，靠"助推裴延是真凶"来加速裁决、自保过关。
7. **零号（玩家）→ 全站**：他掌握的审计权限是全场最大的信息枢纽——但他自己也是秘密的一部分。

## 一条可用的推理链（供玩家串联）

> 回声周期漂移 **0.7 秒** → 门锁日志 **0.7 秒空隙** → NORA 备份 **0.7 秒过度修复痕** → 三处"0.7"指向同一来源：**有人故意在证据里留了同一个指纹。**
>
> 顺着这个指纹，玩家会发现：把证据做得"太完美又留破绽"的，不是凶手，而是"死者"自己。
