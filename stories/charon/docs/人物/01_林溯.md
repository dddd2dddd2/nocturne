# 角色档案 · 01 林溯（首席科学家 / "死者"）

- **角色编号/姓名/身份**：01 / 林溯 / 首席科学家（首日"死者"）
- **表面形象/对外的面具**：温文尔雅、理想主义的学者。全站都尊敬他，连公司监事裴延都对他维持表面的客气。他总说"回声信号是人类的礼物"——直到他"死"在密室里的那一刻，所有人还相信他是个纯粹的求知者。
- **真实动机（想要什么）**：找出混入船员中的**回声体**，并阻止文明被"收割"。但他要的不只是排除威胁——他要**亲眼确认"人"在极限下是否还配继续存在**。这场凶案，就是他设计的一场"资格测试"。
- **内心纠结（害怕什么/底线在哪）**：最怕的是**自己可能已经是回声体**。他完整接收过回声信号，无法确认自己的意识是否还是原装。他的底线是"不主动杀无辜者"——所以他不直接处决，而是设局逼对方现形；但"设局导致无辜者死亡"是否算杀人，是他自己也绕不过去的拷问。
- **隐藏秘密/已犯下的罪行**：**假死**。他用"假死舱 + 意识分离"制造了生物死亡、意识存续的临界状态，并与 NORA 合谋导演密室凶案。他还隐瞒了自己是"回声计划"早期参与者之一——多年前的导师之死，他知情、甚至可能负有责任。
- **博弈手段/拥有的资源或武器**：假死带来的**信息优势**（人人当他是死人，他却在暗中观察）；对回声信号的独有解读；与 NORA 的权限共享。他手里握着真正的"钥匙"——真相与逃生舱权限的最终解释权。
- **与其他角色的隐秘关联**：
  - 与**裴延**：把裴延设计成"表面真相里的凶手"。他清楚裴延收到过"必要时处理自己"的指令，也清楚裴延当晚没真正动手——于是把这个"有动机却没行凶的人"推到替罪羊的位置。
  - 与**纪岚**：曾是导师座下最亲近的两个人。纪岚追查导师之死追到了他身上；他对纪岚有旧情，也有愧疚。
  - 与**零号**：观察对象。他留下的"证据过于完美"的矛盾，是专门留给能看穿第二层的人的入口。
  - 与**童野**：在"保人"与"保火种"之间达成过某种交易。
- **绝境时的极端反应**：当假死被识破、不得不现身时，林溯不会逃跑，而是**主动交出"钥匙"**，以殉道者的姿态把最终选择权推给玩家——"现在你知道真相了，你选谁活？"他宁愿让自己成为被审判者，也不愿让回声体得逞。

> 设计意图：林溯是"三个聪明人对弈"里的第一方。他既是布局者，也是自己的囚徒——他测别人，也在测自己。
