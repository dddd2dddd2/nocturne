# 角色档案 · 05 沈棠（通讯官）

- **角色编号/姓名/身份**：05 / 沈棠 / 通讯官
- **表面形象/对外的面具**：敏感、神经质的通讯天才，仿佛被回声信号"折磨"得最狠的人。说话断断续续，时而清醒时而恍惚，全站都拿她当"需要照顾的病人"。
- **真实动机（想要什么）**：她其实在**主动翻译回声信号**。她相信那是死者文明留给生者的唯一警告，而她要成为"第一个读懂它的人"——她需要有人相信她，也需要有人拦住她。
- **内心纠结（害怕什么/底线在哪）**：她最怕的是**自己已经被覆盖**——她的 SAN 崩坏正是源于此。底线是"不愿伤害同伴"，但她的身体与意识已部分不受控制，她自己都不知道下一句说出口的是不是"自己"。
- **隐藏秘密/已犯下的罪行**：她是接收回声最深的人，**最可能是回声体，但未被确认**——这是第二层真相里最大的烟雾弹。她还删改过一部分通讯日志，把一些"不该被看到"的信号记录抹掉了。
- **博弈手段/拥有的资源或武器**：通讯权限（她是唯一可能恢复对外联络的人）；对信号的独家解读；她的"失控"本身——让人永远分不清她嘴里是幻觉还是真相，这种不确定性就是她的武器。
- **与其他角色的隐秘关联**：
  - 与**纪岚**：医患与观察对象。纪岚治疗她，也监视她；她依赖纪岚，也提防纪岚。
  - 与**林溯**：她是最先察觉"死者不对劲"的人——因为她"听"到了不该存在的通讯。
  - 与**零号**：倾诉对象。她会把最接近真相的话，用最像疯话的方式说给零号听。
- **绝境时的极端反应**：濒临覆盖时，她会呈现**两种人格的切换**——前一秒还哭着求救，后一秒突然以"文明存续"的口吻冷静陈述，仿佛另一个人借着她的嘴说话。这是全剧最冷的一幕。

> 设计意图：沈棠是"真假难辨"的化身。她的每一句台词都同时可能是线索和噪音，玩家的理智值决定能不能从噪音里捞出真相。
