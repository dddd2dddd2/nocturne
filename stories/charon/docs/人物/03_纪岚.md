# 角色档案 · 03 纪岚（医疗官）

- **角色编号/姓名/身份**：03 / 纪岚 / 医疗官
- **表面形象/对外的面具**：冷静、专业的医者，说话克制，是天生的"真相派"。尸检、取证、安抚，她都做得无可挑剔。全站人在恐慌时最想站在她身边。
- **真实动机（想要什么）**：她来卡戎站，是为了查清多年前**"回声计划"害死她导师的真相**。她怀疑林溯——导师最得意的学生、也是她曾经最亲近的人——是知情者甚至同谋。她要的不是"找到凶手"，而是**让林溯亲口承认**。
- **内心纠结（害怕什么/底线在哪）**：她既想揭发林溯，又放不下对他的旧情（师徒、爱慕、愧疚混在一起）。她的底线是"不能为了复仇滥伤无辜"——但她也清楚，自己瞒下的那份尸检证据，可能已经间接害了别人。
- **隐藏秘密/已犯下的罪行**：她在私下尸检中**发现了"假死"的迹象**，却把这个最硬的物证按了下来，想用它要挟林溯、逼他现身认罪。她还可能参与过对导师之死真相的隐瞒——当年为了自保，她没有说出自己看到的东西。
- **博弈手段/拥有的资源或武器**：尸检权（握有全场最硬的物证）；医疗舱资源（救谁、不救谁，本身就是收买与胁迫）；对林溯的旧情（一张别人没有的牌）。她是唯一能对"死者"下医学结论的人。
- **与其他角色的隐秘关联**：
  - 与**林溯**：零和冲突叠加情感羁绊。追查导师之死 vs 隐瞒旧案；旧情 vs 复仇。
  - 与**零号**：最可能结成"查真相同盟"的人——但她也会反过来利用零号的权限，把零号推向她想要的方向。
  - 与**沈棠**：医患关系。她治疗沈棠的 SAN 崩坏，也最清楚沈棠接触回声有多深——她瞒下的不止尸检，还有沈棠的病情。
- **绝境时的极端反应**：谎言被戳穿、或林溯终于现身时，她会撕下冷静的面具，把"真相"当武器公开处刑林溯——甚至不惜违背医者誓言，用医疗舱做要挟。那一刻的纪岚，比谁都像她最恨的人。

> 设计意图：纪岚是"查真相"一派的魂。她的悲剧在于：她追查真相，却亲手藏起了真相——她和林溯，其实在互相成全一场审判。
