# 角色档案 · 04 陈戍（安保长 / 工程师）

- **角色编号/姓名/身份**：04 / 陈戍 / 安保长·工程师
- **表面形象/对外的面具**：沉默、可靠的硬汉。只谈系统和权限，不谈感情。哪里漏气、哪里断电，他第一个去修。所有人默认"陈戍在，站就不会塌"。
- **真实动机（想要什么）**：**活着回地球**。他的妻儿在地球等他。为了这个目标，他可以牺牲任何人，也可以保任何人——一切取决于哪条路离家更近。
- **内心纠结（害怕什么/底线在哪）**：他曾为公司的"清理行动"卖过命，间接害死过无辜的人。他想赎罪，又不敢承认。底线是"不再做那个按下按钮的人"——但当"回家的路"摆在面前时，他不知道自己还守不守得住。
- **隐藏秘密/已犯下的罪行**：他掌握一套**只有他知道的后门权限**，能绕开 NORA 打开部分舱门、甚至逃生舱——这是终局最关键的一张牌。他还隐瞒了凶案当晚**见过林溯**：林溯给了他一个选择，他至今没决定。
- **博弈手段/拥有的资源或武器**：物理权限与后门；对监控盲区的知识；武力威慑。他是全站唯一能"不靠 NORA"行动的人。
- **与其他角色的隐秘关联**：
  - 与**白烬**：零和冲突。逃生舱的钥匙在白烬手里，后门在他手里——两个人都在赌"唯一的生路"归谁。
  - 与**童野**：全站唯一把他当朋友的人。而陈戍清楚，真到绝境时，自己很可能第一个牺牲掉童野。
  - 与**林溯**：凶案当晚的密谈对象。他隐瞒了这次会面，也隐瞒了林溯给他的选择。
- **绝境时的极端反应**：当"回家"与"良心"只能二选一时，陈戍会做出与表面相反的选择——要么是全场最狠的一次自我牺牲，要么是变成全场最冷血的人。**他究竟会站哪边，取决于玩家之前怎么对待他。**

> 设计意图：陈戍是"物理层博弈"的另一半。他不玩话术，只握权限——谁拿到他的后门，谁就多一条命。
