# 角色档案 · 06 白烬（领航员 / 驾驶员）

- **角色编号/姓名/身份**：06 / 白烬 / 领航员·驾驶员
- **表面形象/对外的面具**：玩世不恭的痞子，开口闭口"我想活下去"，把自私摆在明面上。他是"回地球派"的招牌，最会煽动——因为他最敢说大家心里最不敢说的话。
- **真实动机（想要什么）**：**独占逃生舱。** 他知道逃生舱的座椅够坐满全员，但维生系统已被风暴耗尽、只够一个人（或他知道自己已亲手把满员逃生的条件破坏掉），所以早在心里判了所有人死刑。他不是最坏的，只是最先放弃集体的人。
- **内心纠结（害怕什么/底线在哪）**：他其实比谁都怕**一个人孤独地活着**。底线是"不亲手杀人"——但"利用别人去死"算不算，他自己都骗自己说不算。
- **隐藏秘密/已犯下的罪行**：逃生舱密钥在他手里；他**早已对推进器动过手脚 / 隐瞒了逃生条件**，是"只能活一个"局面的直接制造者。更深处，他可能还背着公司"必要时销毁整站"的清理指令。
- **博弈手段/拥有的资源或武器**：逃生舱密钥；领航权限；煽动"回地球派"的能力；最大的信息差——他比谁都清楚物理倒计时真实剩余的时间，也清楚逃生舱的真实载量。
- **与其他角色的隐秘关联**：
  - 与**陈戍**：零和冲突。密钥 vs 后门，两条通往逃生舱的路，只能有一个赢家。
  - 与**裴延**：同派而互相利用。两人都想要那艘逃生舱，都等着对方先动手、自己摘果子。
  - 与**童野**：他需要童野维持氧气，又防着童野分走资源。
  - 与**零号**：试探与拉拢的对象——他总想确认零号会站哪边。
- **绝境时的极端反应**：被逼到绝路时，他会**先发制人，抢先启动逃生舱脱离程序**，把所有人锁在站里等死。他是"物理层面"最直接、最不遮掩的威胁。

> 设计意图：白烬是倒计时最锋利的刀刃。他把"生存 vs 集体"的博弈摆到台面上，逼所有人——包括玩家——直面一个脏问题：你，真的会为别人去死吗？
