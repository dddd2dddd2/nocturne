# 角色档案 · 07 童野（植物学家 / 生命维持工程师）

- **角色编号/姓名/身份**：07 / 童野 / 植物学家·生命维持工程师
- **表面形象/对外的面具**：全站最无害的老好人。种菜、修氧气、谁有难帮谁，永远笑眯眯。没人提防他，因为所有人都觉得"童野能有什么坏心思"。
- **真实动机（想要什么）**：他是**隐藏最深的知情者**。他想保住站里的**种子库**——那是地球生态的最后备份。在他看来，人类的存续不在这 8 个人身上，而在那些种子里。为此，他可以接受任何人的死亡，包括自己。
- **内心纠结（害怕什么/底线在哪）**：他明知自己该"舍人保种子"，却对每个人都真心实意地好，好到自己也分不清是真善良还是伪装。底线是"不主动害人，但可以见死不救"——而这条底线，正是判断他是否"非人"的试金石。
- **隐藏秘密/已犯下的罪行**：他**私藏了部分氧气与能源**——公共品博弈里那个搭便车的人。他还**知道林溯假死**（当晚他看见了），却选择沉默，因为他与林溯在"保火种"上达成了某种交易。他是第二层真相里最容易被忽略、也最可能是回声体的人选之一。
- **博弈手段/拥有的资源或武器**：生命维持资源的分配权（氧气、能源）；无人设防的"好人面具"（信息通向他，却没人提防他）；种子库（终局"火种"的终极价值）。
- **与其他角色的隐秘关联**：
  - 与**林溯**：知情人与交易对象。他守住假死的秘密，林溯承诺保住种子库。
  - 与**陈戍**：全站唯一的朋友。而陈戍真到绝境时，很可能第一个牺牲他——这段友情是最大的背叛伏笔。
  - 与**零号**：最容易被玩家信任的 NPC，也最可能是最大的背叛——玩家越想靠他，越危险。
- **绝境时的极端反应**：当"见死不救"或"私藏资源"被戳穿时，童野会崩溃忏悔。**而他的忏悔到底是不是真心的，本身就是判断他是否回声体的关键**——回声体不会忏悔，它只会计算。

> 设计意图：童野是"好人陷阱"。他用最无害的脸，藏着全剧最冷的算术题：8 条人命，和一颗能重新长出文明的种子，哪个更重要？
