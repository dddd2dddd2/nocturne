# 角色档案 · 00 零号（主角）

- **角色编号/姓名/身份**：00 / 零号 / 公司外派"观察员·审计员"
- **表面形象/对外的面具**：冷静、克制、按规章办事的"程序人"。对谁都客客气气，对任何事都先记下来、不表态。站上的人私下叫他"公司的眼睛"——因为没有人知道他为什么来，只知道他有一块能查所有日志与门禁记录的审计权限牌。
- **真实动机（想要什么）**：表层是"完成审计、活着回地球"。但在记忆深处，他想搞清楚一件事——**自己到底是谁**。他被抹去了一段记忆，来卡戎站本身就是被安排好的；他既想证明自己是"人"，又隐约害怕答案。
- **内心纠结（害怕什么/底线在哪）**：最怕的不是死亡，而是"发现自己不是人"。他的底线是"不能让无辜者因我的选择而死"——但这底线在倒计时里一次次被挑战：为了找出真相，他必须决定谁的秘密被揭开、谁被指认。
- **隐藏秘密/已犯下的罪行**：记忆被系统性抹除并植入；他是林溯与 NORA 计划里的**"对照组 / 诱饵"**。深层线揭晓时，他的真实身份取决于此前的行为模式——可能是唯一真人，可能是回声体，也可能是林溯留下的最后一张底牌。他"观察者"的权限，本身就是局的一部分。
- **博弈手段/拥有的资源或武器**：审计权限（可调日志、门禁、通讯记录）；中立身份（谁都不信他，但谁都想拉拢他）；以及最重要的——**玩家视角本身**。他不知道的秘密，是全场最大的信息差。
- **与其他角色的隐秘关联**：
  - 与**林溯**：被观察对象与被设计者。林溯故意留下"证据过于完美"的后门，就是留给零号这种人的。
  - 与**裴延**：同为"公司外派"，本该同阵营，却因为都拿着权限而互相提防、互相试探。
  - 与**NORA**：审计权限与 AI 权限的天然博弈——零号查得越深，喂给 NORA 的决策数据越多。
- **绝境时的极端反应**：当"我是谁"的真相被揭穿时，零号会呈现两种极端——要么以"自我了断"证明自己仍有人性；要么彻底否认人性，把自己当成一台只按最优解行动的机器。**他的选择，就是玩家最后的选择。**

> 设计意图：零号不是传统"空壳主角"，而是把"玩家行为=角色本质"这个机制做成人设——你玩成什么样，他就是什么。
