# 01 · 绝对客观时间轴

> 本轴为「上帝视角」的时间线，玩家在游戏内只能窥见一部分（见 [03_信息差矩阵](03_信息差矩阵.md)）。

## 取经之前（十四年前）

| 时间 | 事件 |
|---|---|
| 更早 | 天蓬元帅酒后调戏嫦娥，被贬下凡，投了猪胎 |
| 观音策划 | 取经名单缺一「戏眼」，观音选中高老庄：**第二十四难·高老庄收伏猪悟能**，剧本写成，「此难需一民女为饵」 |
| 秋 | 春桃在后山槐树林撞见对词，告诉翠兰，翠兰不信 |
| 入赘 | 猪妖入赘高家，强娶翠兰；高太公请法师捉妖未果 |
| 数月后 | 春桃「病」亡——被灭口，她是台下的灰 |
| 唐僧师徒路过 | 悟空降伏猪妖，八戒皈依，随唐僧西行；高太公以为太平了 |

## 取经期间（十四年）

| 时间 | 事件 |
|---|---|
| 十四年 | 高太公独力撑起高家：修门楼、打粮食、给翠兰做衣裳；猪圈里留着那头老母猪，「想着他回来好歹有个伴」 |
| 翠兰 | 一直未嫁——被妖强娶过的名声，无人敢娶；她等，或者只是活着 |
| 高太公 | 偷偷攒着给女婿留的东西，包括供桌上那只「龙宫的碗」（他说是猪槽） |

## 取经功成（故事开场前半年）

| 时间 | 事件 |
|---|---|
| 功成 | 唐僧封旃檀功德佛，悟空封斗战胜佛，八戒敕封净坛使者，沙僧金身罗汉 |
| 清场 | 观音下令清理证物：翠兰被灌忘川水（活着喝的），名字从生死簿整页撕掉；春桃之死被归档为「瘟疫」 |
| 回执 | 「此庄香火，此后由地府逐年折算，充取经功果」——高老庄的香火从此进了取经的账 |

## 故事开场（半年后）

| 时间 | 事件 |
|---|---|
| Day 1 | 报喜差官入庄：八戒得道，再不回高老庄。高太公一气而亡（喜报贴上门楣，喜丧同堂） |
| Day 1 夜 | 黄泉路 → 忘川 → 望乡台（看见忘了女儿的翠兰） |
| Day 2 | 阎罗殿见生死簿（阳寿八十四，借走十三年）；崔珏；忘川见春桃 |
| Day 3 | 判词：轮回为猪。高太公不跪，挣断锁链——第一幕收束 |
| Day 3-4 | 冤魂聚义；判官交出判官印；孟婆的秘密；夺生死簿（翠兰那页被撕） |
| Day 5 | 阎罗正殿（他翻到自己的借命页）；翠兰之谜（剧本全貌）；二郎神传旨招安 |
| Day 6 | 举旗（灵幡为旗）——第二幕收束 |
| Day 7 | 天兵压境（水淹天兵）；二郎神阵前；濒危·忘川那口气 |
| Day 8 | 八戒·净坛使者（翁婿对峙）；生死簿·焚与守；观音现身——终局六选一 |
