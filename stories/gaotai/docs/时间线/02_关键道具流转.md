# 02 · 关键道具流转

| 道具 | 起点 | 流转 | 终点（各结局） |
|---|---|---|---|
| **生死簿** | 阎罗殿藏书阁（三层铁柜） | 崔判官看守 → 高太公夺出 → 阎罗送回 → 高太公怀里 | 焚簿：烧了；认亲：留给判官；孤魂：带走了；擂鼓：揣着打上天 |
| **判官印** | 崔判官案头 | 崔珏主动交出（或夺簿时夺得） | 改命唯一凭证；焚簿结局中随簿而焚 |
| **那面灵幡** | 高太公棺材 | 出殡白幡 → 战旗（幡上绣着「问」字） | 擂鼓结局中它成了「问天的大旗」；孤魂结局中扛着走 |
| **孟婆汤** | 孟婆的大锅 | 递向高太公三次（桥头/濒危/终局） | 投猪结局：一饮而尽（尝到井水的甜） |
| **那瓢人间井水** | 孟婆私藏 | 兑进每一锅汤 | 投猪结局的钥匙——忘川水忘事，忘不掉井水的味道 |
| **半边纸毛** | 生死簿上翠兰那一页 | 被高太公攥着/揣着 | 焚簿：化作白蝴蝶飞向翠兰窗台；其余结局：一直揣着 |
| **龙宫的碗** | 高家供桌（八戒说是龙宫碗） | 一直供着 | 认亲结局：八戒回家后，碗又用上了 |
| **金钉耙** | 八戒本命 | 天庭阵上 → 高太公面前 | 认亲结局：扛回高老庄犁地 |
| **黄绸圣旨** | 二郎神 | 招安高太公为高老庄土地 | 撕旨（撕了）；接旨（袖里藏着判官印）；封神结局：最终接住 |

> 道具的流转即主题的流转：**写字的（笔/印/簿）最终落到不认字的人手里；忘事的（汤）被记着的人尝出了家的味道。**
