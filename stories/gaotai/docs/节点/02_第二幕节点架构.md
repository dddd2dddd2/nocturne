# 02 · 第二幕节点架构（地府 · 聚义之怒）

## 节点一览（8 节点）

| 节点 | 标题 | 功能 |
|---|---|---|
| Node_2_1 | 冤魂聚义 | 第一场演说：讲高老庄（人情）/ 讲簿子账（账）/ 问想不想回家（人情+怒） |
| Node_2_2 | 判官对质 | 判官印入手（key）/ 红点真相（卷+人情）/ 拉他入伙（人情） |
| Node_2_3 | 孟婆·汤与桥 | 秘核心：问她忘了什么（秘+人情）/ 尝汤（怒↓+账）/ 请指路（人情+秘） |
| Node_2_4 | 夺簿·生死簿 | 翠兰那页被撕（秘）/ 烧簿冲动（账+怒↓）/ 夺印（key） |
| Node_2_5 | 阎罗正殿 | 掀案桌（怒+人情↓）/ 让他翻自己（账+秘）/ 问天条作者（卷） |
| Node_2_6 | 翠兰之谜 | 剧本全貌：听春桃讲完（卷+怒↓）/ 攥纸沉默（怒↓+人情）/ 大笑（怒↑+秘） |
| Node_2_7 | 天庭来使·二郎神 | 招安：撕旨（怒+卷）/ 接旨稳住（人情↓+账）/ 单独一句话（人情+秘） |
| Node_2_8 | 收束·战旗 | 举旗三向，汇入第三幕 |

## 结构设计

```
Node_2_1 → [Node_2_2 → Node_2_3 → Node_2_4 → Node_2_5 → Node_2_6 → Node_2_7] → Node_2_8 → [第三幕]
           └─────────────── 探索网状（顺序可变） ───────────────┘
```

- 中段六节点是可换顺序的探索网：判官（权力）、孟婆（遗忘）、阎罗（秩序）、春桃（真相）四条线各自独立又互相印证；
- Node_2_2 与 Node_2_4 都能获得判官印（key），保证改命道具不因单一路线丢失；
- 濒危机制在这幕即可能触发（怒意持续走低 → 被拖入第三幕的濒危节点，提前「断气」）；
- Node_2_7 是第二幕的情感反转点：天庭不镇压，先招安——高太公第一次直面「天怕什么」。

## 第二幕主题

> 从「一个人的怒」变成「十万人的怒」——同时，用四条线证明：**地府没有一个坏人，地府办的坏，全在天条里。**
