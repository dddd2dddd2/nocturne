# 03 · 第三幕节点架构（反天 · 问天之怒）

## 节点一览（6 节点 + 6 结局）

| 节点 | 标题 | 功能 |
|---|---|---|
| Node_3_1 | 天兵压境 | 第一仗：引忘川水（怒+账）/ 冤魂齐哭（人情+秘）/ 独身上前（人情+怒↓） |
| Node_3_2 | 二郎神·阵前 | 劝他放行（人情+卷）/ 以命相搏（怒↓+账）/ 喊话见八戒（→濒危） |
| Node_3_3 | 忘川·那口气 | **濒危节点**（怒<30 被强制拖入）：挣扎站起（怒+15 → Node_3_4）/ 喝汤（→End_5） |
| Node_3_4 | 八戒·净坛使者 | 情感顶点：骂他（人情+秘）/ 踹他起来（人情+怒）/ 锁链当刀（人情↓↓） |
| Node_3_5 | 生死簿·焚与守 | 权力顶点：烧了它（账+怒↓）/ 封了它（人情+卷）/ 留着问作者（秘+怒↓） |
| Node_3_6 | 佛光·剧本的作者 | 终极枢纽：六选一进六结局（条件见下） |
| Node_End_1..6 | 六结局 | 无选项，纯收束 |

## 终局枢纽（Node_3_6）六选一

| 选项 | 结局 | 条件 |
|---|---|---|
| 擂鼓，打上凌霄 | End_1 凌霄·擂鼓 | 怒意 ≥ 60 |
| 焚了生死簿 | End_2 焚簿·还命 | 线索合计 ≥ 25 |
| 认下这门亲，带八戒回家 | End_3 高老庄·认亲 | 人情 ≥ 8 |
| 接过神位 | End_4 封神·灶神 | 人情 ≤ 3 且 怒意 ≤ 45 |
| 喝下孟婆汤 | End_5 忘川·投猪 | 怒意 ≤ 30 |
| 谁也不理，做孤魂野鬼去 | End_6 孤魂 | 线索合计 ≥ 25（无条件保底） |

> 终局枢纽刻意让六种选择「读起来都是同一件事的不同说法」——打天、放火、回家、为官、喝汤、独走，区别只在变量。玩家前二十几个节点攒下的怒意/人情/线索，在这里决定高太公是谁。

## 第三幕主题

> 把「反天」从战争题材拉回本体问题：**一个人，要不要认命？** 六种结局没有一个「胜利」——只有不同的「认」法。
