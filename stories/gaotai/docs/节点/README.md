## 与引擎的约定

- 节点命名 `Node_1_x / Node_2_x / Node_3_x / Node_End_x`（引擎约定，见 `src/engine/types.ts`）；
- `Node_3_3` 为「濒危节点」：怒意（sanity）< 30 时被引擎强制拖入；`Node_3_4` 为豁免节点（引擎不在此强制转移）；
- 怒意 = 0 时引擎强制进入 `Node_End_4`（封神·灶神）——「怒气散尽的人最好招安」；
- 变量语义与判定公式见 [大纲/04_核心机制变量](../大纲/04_核心机制变量.md)。
