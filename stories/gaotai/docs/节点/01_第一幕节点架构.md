# 01 · 第一幕节点架构（高老庄 · 地上之怒）

## 节点一览（8 节点）

| 节点 | 标题 | 功能 |
|---|---|---|
| Node_1_1 | 开场·喜报 | 开场三选：听喜报（账）/ 掀桌（怒+人情）/ 看翠兰（秘+怒↓） |
| Node_1_2 | 断气·那口气 | 死前三选：问明白 / 骂完 / 咽气看翠兰 |
| Node_1_3 | 黄泉路 | 路上三选：问翠兰在簿上否 / 数步子 / 挣锁链 |
| Node_1_4 | 望乡台 | 回望三选：细看翠兰（秘）/ 看喜报（账+怒↓）/ 扭头（怒+人情↓） |
| Node_1_5 | 阎罗殿·生死簿 | 核心披露：阳寿八十四借走十三年；三选给三类线索 |
| Node_1_6 | 判官崔珏 | 对话三选：问阳寿（账）/ 问翠兰（秘）/ 求明路（人情） |
| Node_1_7 | 忘川·春桃 | 核心披露：高老庄一难是戏；三选：哭（人情）/ 问作者（卷）/ 问翠兰（秘） |
| Node_1_8 | 收束·那一跪 | 收束三选，全部汇入第二幕：跪认（怒↓）/ 直腰（怒↑）/ 挣断（怒↑↑） |

## 结构设计

```
Node_1_1 → Node_1_2 → Node_1_3 ─┬→ Node_1_4 → Node_1_5 → Node_1_6 → Node_1_7 → Node_1_8 → [第二幕]
                                  └→ (Node_1_5 可先行)
```

- 前四节点是「地上」，后四节点是「地府」；望乡台与阎罗殿的顺序可换（网状小分支）；
- 每个节点三选，分别倾向 账/卷/秘 或 怒意/人情 的不同积累——第一幕结束时，玩家已经「偏科」，这决定第二幕他能看见什么；
- Node_1_5 是信息核心（生死簿），Node_1_7 是情感核心（春桃），Node_1_8 是意志分水岭（跪 or 不跪）。

## 第一幕主题

> 把一个种地的老头，从「寿终正寝的糊涂鬼」变成「不认命的鬼」——三样东西缺一不可：账（命被借）、卷（戏是写的）、情（女儿被抹）。
