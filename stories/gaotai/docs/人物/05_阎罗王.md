# 角色档案 · 05 阎罗王

- **角色编号/姓名/身份**：05 / 阎罗王 / 十殿之主，生死轮回的看守
- **表面形象**：黑脸红袍，胡须垂到胸前，千年未离正殿——地府秩序的活招牌。
- **真实动机**：守规矩。他见过没有规矩的乱，所以信规矩——哪怕那规矩是别人写的。
- **内心纠结**：他是全剧最标准的「办事的人」。他不是恶人，他只是在执行；而执行本身，办了最多的命。当他翻到生死簿上自己那一页（阳寿七十二，借走三十年，以充幽冥守门之职）时，他的指节泛白——他守的规矩，头一个借的就是他自己的命。
- **隐藏秘密**：
  - 他做阎罗之前也是鬼，也是借命的人；
  - 他知道天条不是天庭写的——天庭只是抄书的人，真本在西天。
- **与其他角色的隐秘关联**：
  - 与**高太公**：官 vs 民。他的「天条在上」，对高太公的「那就改」，是秩序与人的第一场正面冲突。
  - 与**崔珏**：上下级，也是同谋——他们都知道簿子有鬼，一个用红点记，一个用沉默守。
- **结局去向**：焚簿结局中，簿子是他让鬼差送来的——「老夫守了千年，守够了」。他大概是全书唯一一个「把簿子交出去」的官。
