# 角色档案 · 02 猪八戒（净坛使者）

- **角色编号/姓名/身份**：02 / 猪悟能·八戒 / 高家猪头女婿，取经功成后敕封净坛使者
- **表面形象/对外的面具**：天庭的新贵——披金线袈裟、扛金钉耙、圆滚滚的净坛使者，享受十方供品。对谁都是笑嘻嘻的，一副没心没肺的样子。
- **真实动机**：表层是「了却尘缘」；深处是**找翠兰**——他查过生死簿，小姐的名字被人抹了，他找了十四年。他以为取经能保高家平安，结果取经本身就是高家的劫。
- **内心纠结**：他既恨自己的出身（猪），又认自己的出身（高老庄的猪圈是他这辈子睡过最安稳的地方）；他成了神，却忘不掉自己是高家的女婿。全剧最重的罪，是「信了菩萨的话」。
- **隐藏秘密**：
  - 净坛使者听着风光，差事是替神佛收拾剩饭供品——名为成神，实为天界的净差，他自己心里门儿清；
  - 他成神那天问过菩萨：高老庄那个小姐还好吗？菩萨说：她很好，已经忘了。
- **与其他角色的隐秘关联**：
  - 与**高太公**：翁婿。他跪高太公，是全剧情感顶点——一个神跪一个老鬼，跪的是他这辈子唯一喊过「爹」的人。
  - 与**翠兰**：夫妻。他的「找」，和翠兰的「忘」，是同一枚硬币的两面。
  - 与**二郎神**：同僚。二郎神替他把话传到阵前。
- **结局去向**：认亲结局中，他脱了袈裟，扛着钉耙回家种地；擂鼓结局中，他是天兵营里那个「不打的」；投猪结局中，高太公投了猪胎——走的就是他当年的路。
