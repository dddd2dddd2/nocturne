# 角色档案 · 06 孟婆

- **角色编号/姓名/身份**：06 / 孟婆 / 忘川桥头的掌汤人
- **表面形象**：干瘦的老妇人，头发全白却梳得整整齐齐，千年不变的微笑——笑眯眯地递汤，笑眯眯地看着每个鬼喝下去。
- **真实动机**：表层是「守桥」；深处是替放不下的人留一条缝。
- **内心纠结**：她是这桥上第一个端碗的人，那碗汤是她自己先尝的——她忘了自己的孩子，忘了自己姓什么，忘了自己忘过什么。她不是慈悲，也不是残忍，她是「上头的意思」本身；但她在锅底藏了一瓢人间井水。
- **隐藏秘密**：
  - 孟婆汤一半给死人（慈悲），一半给活人（维稳）——活人被灌忘川水，是秩序的一部分；
  - 她是第一个被忘川水抹掉记忆的人；
  - 她偷偷在汤里兑了一瓢人间井水——「喝的人，若是心里真有事，那瓢井水，能让他想起点啥来」。
- **与其他角色的隐秘关联**：
  - 与**高太公**：汤与桥。她递汤，他拒汤；她的那瓢井水，是投猪结局的关键——高太公在苦汤里尝到了高老庄井水的甜。
  - 与**翠兰**：间接——翠兰被灌的，就是她的汤。
- **结局去向**：投猪结局里，她看着高太公喝完；孤魂结局里，她大概还在桥头，等着下一个不肯喝汤的鬼。
