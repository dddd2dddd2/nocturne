# 角色档案 · 04 崔珏（阴间判官）

- **角色编号/姓名/身份**：04 / 崔珏 / 执掌生死簿的判官，阴间最会写字的人
- **表面形象**：青袍老吏，袖口一块磨不掉的墨渍，说话慢，办事稳，判了一千年案，没出过错。
- **真实动机**：表层是「守规矩」；深处是**记着**——他判不了自己的良心，就把每个冤死的人记下来。
- **内心纠结**：他是官，官不能反；可他一千年点了一千个红点，就是在等一个能改命的人。他交出判官印时说的那句「改命不是闹着玩的」，是真话——他比谁都清楚改命的代价。
- **隐藏秘密**：
  - 每个冤死的人，他都在名字旁点一个红点，再在自己胳膊上扎一针——一千年，一千针；
  - 判官印是他故意交出去的——他等一个敢改命的人，等了一千年；
  - 他知道翠兰的名字被抹，但他不敢说——他说「生死簿上没有高翠兰」，是全书最轻、最重的一句话。
- **与其他角色的隐秘关联**：
  - 与**高太公**：笔与簿。他给高太公指路（「别让那口气咽下去」），也把自己的印给了他。
  - 与**阎罗王**：上下级。他奉命判案，阎罗奉命坐堂——地府没有自由人。
- **结局去向**：焚簿结局里他说「这一千针算是白扎了」，高太公答「不白扎——它们如今在天下人心里」。封神结局里，他大概还是那个记红点的判官。
