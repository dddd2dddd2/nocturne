# 角色档案 · 00 高太公（主角）

- **角色编号/姓名/身份**：00 / 高太公 / 高老庄庄主，七十岁，死后反天的老鬼
- **表面形象/对外的面具**：庄里最体面的老头——当过庄主，养大女儿，修过门楼，打过粮食，一辈子没求过人。庄里人说他是「高家的门面」。
- **真实动机（想要什么）**：表层是「问个明白」（女儿的名字在哪一页、阳寿被谁借走）。深处是**要回那口气**——他这辈子都在按簿子上写的活，死到临头发现簿子是别人的，他想把「自己」要回来。
- **内心纠结（害怕什么/底线在哪）**：怕的不是死，是**被忘记**（女儿忘了他，名字被抹，他怕自己这一辈子在簿子上连个名字都算不上）。底线是「不认命的鬼」——想不通，就不能跪。
- **隐藏秘密/已犯下的「罪」**：按天条，他「诽谤神明」（骂了女婿一句），判词是轮回为猪。他不知道也不在乎——他连命都是借的，判什么都是空的。
- **博弈手段/拥有的资源**：庄稼人的理（水淹天兵、人海战术）；判官印；十万冤魂；那面绣着「问」字的灵幡；以及全剧唯一不会耗尽的东西——记性。
- **与其他角色的隐秘关联**：
  - 与**翠兰**：父女，也是全剧的根。他做的一切，最后都回到女儿身上。
  - 与**八戒**：翁婿。爱恨交缠——恨他害了女儿，心疼他把自己搭进去；他是全剧唯一喊他「爹」的神。
  - 与**崔珏**：笔与簿的对手，也是忘与记的同谋。崔珏攒红点，他攒那口气。
  - 与**孟婆**：不肯喝汤的人与让人喝汤的人——她的秘密（那瓢井水）是投猪结局的钥匙。
- **绝境时的极端反应**：气散了就喝汤（投猪）；气还在就打上天（擂鼓）；两头都不是，就谁都不认（孤魂）。**他的选择，就是玩家最后的选择。**
