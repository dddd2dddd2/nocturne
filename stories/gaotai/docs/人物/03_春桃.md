# 角色档案 · 03 春桃

- **角色编号/姓名/身份**：03 / 春桃 / 高家丫鬟，伺候翠兰，死后成了忘川边的冤魂
- **表面形象**：穿一件洗得发白的桃红衫子（高太公十四年前花二两银子给她扯的料子，她舍不得穿），说话轻声细气，见了老爷先哭。
- **真实动机**：把真相说出去。她死了十四年，在忘川边坐了一十四年，等的就是老爷。
- **内心纠结**：她撞见过对词，却没有拦住那出戏——她跟翠兰说过「有人要拿你写戏」，翠兰只当她戏听多了。她到死都背着一句「我该早点说」。
- **隐藏秘密（她知道的全部）**：
  - 她是被灭口的——「戏演完了，你是台下的灰，灰要扫干净」；
  - 她亲耳听过剧本：「第二十四难，高老庄收伏猪悟能」「此难需一民女为饵，事毕，将证物清干净」；
  - 翠兰被灌忘川水是在取经功成之后——「角儿要留着，等戏散了，再让她忘干净」。
- **与其他角色的隐秘关联**：
  - 与**高太公**：主仆，也是他把真相带进阴间的人——没有春桃，高太公只会是一个「阳寿被借」的糊涂鬼。
  - 与**翠兰**：主仆情深。她的死，是翠兰之忘的前奏。
- **结局去向**：焚簿结局里她看着火烧了一夜；孤魂结局里她喊「老爷」；高太公走时对她说：替老爷看着这川的鬼，别让他们喝那碗汤。
