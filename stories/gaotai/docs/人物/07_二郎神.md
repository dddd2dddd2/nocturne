# 角色档案 · 07 二郎神

- **角色编号/姓名/身份**：07 / 二郎真君·杨戬 / 天庭钦差，传旨领兵的人
- **表面形象**：银甲金冠，三尖两刃刀，额上三只眼——天庭最能打的钦差，公事公办，不怒自威。
- **真实动机**：表层是「奉命行事」；深处是**旁观**——他是全剧最接近「中立」的神。
- **内心纠结**：他是玉帝的外甥，半人半神，听调不听宣。他在天上不是正正经经的自己人——所以他比任何神仙都懂「外人」是什么滋味。高太公问他「您在天上，也是外人吧」，他撤了半队天兵。
- **隐藏秘密**：
  - 他传旨那天故意撤了半队天兵；
  - 他知道高太公的问题问到了点子上——但他只负责传旨、领兵，不负责讲理。
- **与其他角色的隐秘关联**：
  - 与**高太公**：天兵 vs 反贼。他是高太公在天庭遇到的第一个「不是铁板一块」的人。
  - 与**八戒**：同僚。他替八戒把「让我丈人来见我」的话传到阵前。
- **结局去向**：擂鼓结局里，他站在凌霄宝殿，看着那面擂不完的鼓；孤魂结局里，他大概会望着高太公走远的方向，什么也没说。
