## 人物设计总则

- **没有一个纯粹的坏人**：阎罗是守规矩的，崔珏是记红点的，二郎神是传旨的，连写剧本的观音都「慈悲」——这出戏里没有恶人，只有「办事的人」。恶，是办事办出来的。
- **每个人都「忘了」点什么**：孟婆忘了孩子，阎罗忘了自己借过命，八戒忘了该回高老庄，翠兰忘了一切。只有高太公（以及替他记着红点的崔珏）不肯忘。
- **主角不是英雄，是庄稼人**：高太公的所有胜利都用种地的逻辑打出来；他的所有失败，都因为他是种地的——他太知道「命」是怎么回事了。
