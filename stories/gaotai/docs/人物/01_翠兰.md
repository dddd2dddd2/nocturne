# 角色档案 · 01 高翠兰

- **角色编号/姓名/身份**：01 / 高翠兰 / 高太公之女，独居高老庄
- **表面形象/对外的面具**：一个神思恍惚的老妇人，坐在窗下看天，谁也不认得，谁问都答「你是谁呀」。
- **真实动机**：无——她的记忆被拔掉了。她的存在本身，就是全剧最重的证物。
- **内心纠结**：她没有内心，只有那口枯井似的眼睛。读者（和高太公）要在她的空里，看见那出戏。
- **隐藏秘密/已犯下的「罪」**：
  - 名字被从生死簿上**整页撕掉**——她是「高老庄一难」的戏眼，证不能留在簿上；
  - 取经功成后被灌了忘川水，**活着喝的**——为了让她忘掉自己是诱饵。
- **与其他角色的隐秘关联**：
  - 与**高太公**：父女。她的「忘」，是父亲「记」的全部理由。
  - 与**八戒**：名义上的夫妻。八戒找了她十四年，找到的只有「她很好，已经忘了」。
  - 与**春桃**：主仆。春桃是唯一拼死想告诉她「有人要拿你写戏」的人。
- **结局去向**：焚簿结局中，她名字所在的那半边纸毛化作白蝴蝶，落在她手心；认亲结局里，蝴蝶落手时她叫了一声「爹」。她始终没有「想起」——但蝴蝶替她想起来了。
