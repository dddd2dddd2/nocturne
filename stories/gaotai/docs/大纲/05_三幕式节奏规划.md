# 05 · 三幕式节奏规划

## 第一幕 · 高老庄（地上之怒）—— 起因

- **剧情**：喜报入庄（八戒得道）→ 断气 → 黄泉路 → 望乡台 → 阎罗殿见生死簿（发现阳寿被借）→ 判官崔珏 → 忘川见春桃（高老庄一难是戏）→ 判词「轮回为猪」→ 那一跪 / 那一挣。
- **情绪曲线**：荒诞（喜丧同堂）→ 愤怒（簿子借命）→ 崩塌（女儿的名字被抹）→ 决裂（不跪）。
- **节点结构**：线性中带小分支（望乡台 / 阎罗殿的先后、面对判官与春桃的态度），全部汇入收束节点「那一跪」。
- **核心目的**：让玩家和高太公一起，把「种地的常识」与「天条的账本」之间的裂缝看清楚。

## 第二幕 · 地府（聚义之怒）—— 激化

- **剧情**：冤魂聚义（第一场演说）→ 判官交出判官印 → 孟婆的汤与井水 → 夺生死簿（翠兰那页被撕）→ 阎罗正殿（他也是借命的人）→ 翠兰之谜（剧本全貌）→ 二郎神传旨招安 → 举旗。
- **情绪曲线**：从「一个人的怒」变成「十万人的怒」；每一段都进一步证实：没有人是坏人，所有人都只是「办事的」——而办事的，办掉了天底下最多的命。
- **节点结构**：网状探索（判官 / 孟婆 / 阎罗 / 春桃四条线可换顺序），汇入收束节点「战旗」。
- **核心目的**：把个人冤屈扩展成制度之冤；同时埋下所有结局的伏笔（判官印、井水、二郎神的松动、八戒的下落）。

## 第三幕 · 反天（问天之怒）—— 爆发与收束

- **剧情**：天兵压境（第一仗，种地式打法）→ 二郎神阵前 → 濒危节点「忘川·那口气」→ 八戒·净坛使者（翁婿对峙，全剧情感顶点）→ 生死簿·焚与守 → 佛光·剧本的作者（观音现身）→ 终局六选一。
- **情绪曲线**：怒到极致（打天）→ 软到极致（八戒下跪）→ 冷到极致（看破剧本）→ 交给玩家收尾。
- **节点结构**：以濒危节点为支点、以翁婿对峙为高潮的收敛结构，最后在佛光下展开六种结局。
- **核心目的**：把「反天」从战争题材拉回「一个人要不要认命」的本体问题——天兵打不完，但六种结局里，只有一种是高太公自己的。

## 六结局定位

| 结局 | 姿态 | 一句话 |
|---|---|---|
| 凌霄·擂鼓 | 战 | 刑天式的：赢不了，也停不下来 |
| 焚簿·还命 | 法 | 把命还给天下人，接受随之而来的乱 |
| 高老庄·认亲 | 家 | 唯一的善终：带猪头女婿回家种地 |
| 封神·灶神 | 体制 | 反贼被招安成灶台的监视眼 |
| 忘川·投猪 | 忘 | 喝汤轮回为猪，走一遍女婿的老路 |
| 孤魂 | 自由 | 谁都不认，独自走进风里 |
