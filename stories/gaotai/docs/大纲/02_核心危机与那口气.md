# 02 · 核心危机与「那口气」

## 双线压力

本作没有「倒计时」，替代它的是两条互相拉扯的线：

1. **天兵压境的倒计时**：地府闹鬼的消息传到天庭，不到一个时辰，天兵就压下来。天庭的第一波是招安（高老庄土地），第二波是二郎神领兵，第三波是净坛使者（八戒）被推上战场，最后是观音亲临——压力一波比一波高，逼高太公在每一波之间做决定。
2. **那口气将散**：怒意（sanity）不是战斗力，是「存在」本身。气散了，人就会过桥、喝汤、投胎——游戏结束。怒意 < 30 时，玩家会被强制拖入濒危节点「忘川·那口气」，直面孟婆的汤：站起来（+15）还是喝下去（结局5）。

## 博弈核心

高太公的真正对手，从来不是阎罗、二郎神或天兵，而是 **「写书人」**：

- 他打得过鬼差，打得过判官，打得过天兵——这些都只是「抄书的人」；
- 他打不过的是「第二十四难」四个字底下那套逻辑：你的命是定数，你女儿的命是定数，你受的苦是功德。这套逻辑没有敌人，它只是「写着」。
- 所以本作每个关键节点的选择，本质都是同一个选择：**信定数，还是信自己？** 六个结局，是这同一个选择在不同变量组合下的六种答案。
