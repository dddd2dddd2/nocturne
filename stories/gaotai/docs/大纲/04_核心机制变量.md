# 04 · 核心机制变量

引擎变量语义（与 `src/engine/engine.ts` 的钳位/条件规则一致；面板文案见 `story.ts` 的 `varLabels`）：

| 变量 | 本作语义 | 起止 | 作用 |
|---|---|---|---|
| `sanity` | **怒意·那口气** | 0–100（初始 70） | 主角存在的根基。归零 → 怒气散尽，被强制拖入结局4（封神·灶神：散气的人最好招安）；<30 → 强制进入濒危节点「忘川·那口气」 |
| `bond` | **人情** | 0–100（初始 0） | 与翠兰、春桃、八戒、崔判官、孟婆、二郎神的牵连。认亲结局（3）的人情门槛 |
| `clue_a` | **账·生死簿** | 0–40 | 阳寿被借、名字被抹的实证——第一层真相 |
| `clue_b` | **卷·取经剧本** | 0–40 | 高老庄一难是写好的戏——第二层真相 |
| `clue_c` | **秘·轮回真相** | 0–40 | 忘川、孟婆汤、天条的作者——第三层真相 |
| `key` | **判官印** | 布尔 | 改生死簿的唯一凭证，崔判官或夺簿时获得 |

## 判定公式（结局门槛，见 `docs/结局/`）

| 结局 | 门槛 |
|---|---|
| End_1 凌霄·擂鼓 | `怒意 ≥ 60` |
| End_2 焚簿·还命 | `线索合计 ≥ 25` |
| End_3 高老庄·认亲 | `人情 ≥ 8` |
| End_4 封神·灶神 | `人情 ≤ 3` 且 `怒意 ≤ 45`（怒气散尽时强制进入） |
| End_5 忘川·投猪 | `怒意 ≤ 30`（或濒危节点喝汤） |
| End_6 孤魂 | `线索合计 ≥ 25`（终局枢纽的无条件保底出路） |

> 变量不是「数值博弈」而是「性格塑造」：同一局游戏里攒起来的怒意/人情/线索，最后会决定高太公是以哪种身份收场——战死、放火、回家、为官、轮回，还是独走。
