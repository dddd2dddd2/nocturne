# 03 · 表面真相与隐藏真相（三层真相）

本作有三层递进的真相，对应三类线索（账 / 卷 / 秘）：

## 第一层 · 账（clue_a）：我的阳寿被借了

- **表面**：高太公寿终正寝，享年七十一，死因「一气而亡」。
- **真相**：生死簿上写得清清楚楚——阳寿八十四，**借走十三年，借与取经功果**。那猪头女婿的「得道」，是用老丈人十三年的命换的。而按天条，他连质问的资格都没有，还要「谢恩」。
- 这是全剧的引子：一个种地的，发现自己连命都不是自己的。

## 第二层 · 卷（clue_b）：高老庄一难是写好的戏

- **表面**：十四年前猪妖强娶民女，唐僧师徒路过，收了妖，庄里恢复太平。
- **真相**：观音菩萨亲手安排的一出戏——「第二十四难：高老庄收伏猪悟能」。菩萨借了猪（天蓬元帅投胎）、借了门楣、借了翠兰的身子，写了「强娶民女、降妖伏魔」的剧本。春桃撞见对词，被灭口；翠兰是「戏眼」，戏散了要「忘干净」。
- 这一层让高太公明白：他全家从头到尾都是戏台上的布景，「一难」两个字的注脚。

## 第三层 · 秘（clue_c）：轮回、忘川与天条的作者

- **表面**：生死轮回是天地正道，孟婆汤是慈悲，天条是天庭定的。
- **真相**：
  - 孟婆汤一半给死人（慈悲），一半给活人（维稳）——让受了冤屈的活人忘掉，是秩序的一部分；
  - 阎罗自己也是借命的人（阳寿七十二，借走三十年「以充幽冥守门之职」）——地府没有一个自由人；
  - 天条不是天庭写的，天庭只是抄书的人，真本在西天那位手里；
  - 高太公的阳寿被借、翠兰的名字被抹、春桃被灭口，全部是同一本剧本的成本核算。
- 这一层指向结局前的终极问题：**写书人要不要为书里的人负责？**

## 收束逻辑

三层真相不是并列的，是一条链：**账**（我的命被借了）→ **卷**（原来我是戏里的布景）→ **秘**（写戏的人就是天，而天从不认账）。链走到头，高太公手里就有了六种可能的答案——六种结局。
