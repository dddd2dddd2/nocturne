## 题材说明

本作选择 **《西游记》的边角料重写**，因为高老庄一难在原著里是最轻的一场戏——

- **人人都笑高太公**：招了个猪妖女婿，闹到要请法师捉妖，是全书最市井的笑料；
- **没人问过他一嘴**：女儿被妖强娶、名声被毁、家财被吃，之后呢？取经功成，猪悟能得了正果，他高家得了什么？
- **天然的「写书人 vs 书中人」结构**：原著里高老庄是观音取经局中的一难，高太公一家是「证物」。把他写活，就是把「证物」写成「人」。
- **第一人称的理由**：全作以高太公的口吻叙述——一个种地老农的土话、庄稼话、骂人话，撞上神佛的庄严话语系统，本身就是语言的冲突；而「记 vs 忘」的主题，也只有在「我」的记忆里才能成立。

> 文风取向：泥土的质感 + 神话的荒诞（莫言式的感官密度、民间叙事的重复与变奏、悲喜剧同炉）。正文见 `prose/`，唯一手改处。
