# 01 · 故事背景与舞台

## 时空

- **人间**：唐贞观年间，乌斯藏国界高老庄。取经功成后约半年。高老庄是个种麦、养猪、烧香、纳粮的普通庄子——普通到「连名字都是别人剧本里的一难」。
- **地府**：黄泉路 → 忘川 → 望乡台 → 阎罗殿。阴间不是异界，是阳间的官僚投影：簿子管人，笔杆子管簿子，天条管笔杆子。鬼差按公文办事，判官按簿子下笔，阎罗按天条坐堂——没有一个是坏人，人人都只是「办事的」。
- **天庭**：传旨、领兵、招安的地方。天庭不写天条，只抄天条；天条的真本在西天。天庭的官僚对地府的叛乱第一反应不是镇压，是「给个官做」。

## 舞台规则（本作的地府设定）

1. **生死簿即法**：名字在簿上，命就在簿上。名字被金线划掉 = 超脱生死（神仙）；名字被整页撕掉 = 「等于没活过」（证物清干净）。
2. **轮回是秩序，不是慈悲**：六道轮回是阴间的「地基」——没有轮回，鬼不能投胎，人间就会乱。但这个秩序由西天设计、天庭抄录、地府执行，被借命、被抹名的人，是这个秩序的「损耗」。
3. **忘川水 / 孟婆汤**：一半给死人（慈悲），一半给活人（维稳）。让受了冤屈的人忘掉，是维持秩序的手段。
4. **怒意即那口气**：高太公死后，支撑他行动的不是鬼力，是那口咽不下的气。气散了，他就和所有鬼一样，过桥、喝汤、投胎。
5. **神也会忘**：孟婆忘了一切，阎罗忘了自己曾是借命的人，净坛使者忘了自己该记得高老庄——「得道」和「为官」，都以「忘记」为代价。高太公是全剧唯一不肯忘的人。

## 一句话世界观

> 天庭和地府合起来是一台「改命的机器」；高太公要做的，不是推翻机器，是证明机器改不了人心里那口气。
