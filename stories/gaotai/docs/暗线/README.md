# 《高太公战纪》暗线

> 暗线是「主角未必看见、读者二周目才看全」的线。本作五条暗线互相咬合，最终全部收进「剧本的作者」这一个问题。

|---|---|---|
| [01_取经剧本线](01_取经剧本线.md) | 写书人 | 高老庄一难是观音写好的戏，高太公一家是布景 |
| [02_翠兰线](02_翠兰线.md) | 被抹去的人 | 她的名字被撕，她的记忆被拔——她是戏的证，证不能留 |
| [03_八戒线](03_八戒线.md) | 得道者的代价 | 净坛使者是收拾剩饭的差事；他信了菩萨，菩萨写了他 |
| [04_孟婆线](04_孟婆线.md) | 遗忘机器 | 忘川水一半给死人、一半给活人；孟婆自己是第一个被抹的 |
| [05_判官线](05_判官线.md) | 记红点的人 | 崔珏攒了一千个红点，等一个敢改命的人，等了一千年 |

## 暗线总纲：记 vs 忘

五条暗线其实是同一条线：**天上的秩序，靠「忘记」运转**——
剧本要被忘记（证物清干净），翠兰要被忘记（灌忘川水），孟婆自己被忘记（第一个喝汤），判官不敢忘（只能偷偷扎针记红点），八戒被要求忘记（「她很好，已经忘了」）。
而高太公的全部行动，就是不肯忘。
