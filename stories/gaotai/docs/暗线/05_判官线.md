# 暗线 05 · 判官线

**一句话**：崔珏判了一千年案，每个冤死的人他都在名字旁点一个红点，再在自己胳膊上扎一针——他等一个敢改命的人，等了一千年。

## 埋设节点

| 节点 | 揭示 |
|---|---|
| Node_1_5 阎罗殿 | 「你看见他笔尖顿了顿，在簿角点下一个红点」——第一颗种子 |
| Node_1_6 崔珏 | 「每个冤死的人，老夫都在名字旁点一个点。点了千年，攒了千年」 |
| Node_1_6 | 「你问的那口气，若还堵着——就别让它咽下去」——他给高太公指路 |
| Node_2_2 判官对质 | 他卷起袖子：一千个红点从手腕排到肘弯，「一千年，扎了一千针」 |
| Node_2_2 | 他交出判官印：「老夫是官，官不能反。可印给你，簿子给你」 |
| Node_End_2 焚簿 | 「老夫这一千针，算是白扎了」——高太公答：不白扎，它们如今在天下人心里 |

## 线的尽头

崔珏是全剧唯一一个「既在系统里、又不肯忘」的人：他不能反（官不能反），但他可以记（红点）、可以交（印）、可以指路（那口气）。
他的存在证明了一件事：**天条能改命，改不了人的记性。** 只要有一个判官在扎针，就有一千个冤死的人，在簿子之外，还活着。

> **二周目看点**：数一数崔珏说的「第一次」——「老夫记性不好，怕忘了」是第一次坦白，「等了一千年」是第一次说出等谁。这个老吏每句话都算着说，每句都是真的。
