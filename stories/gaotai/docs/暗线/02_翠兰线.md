# 暗线 02 · 翠兰线

**一句话**：她的名字被从生死簿上整页撕掉，她的记忆被忘川水拔掉——她是戏的证，证不能留。

## 埋设节点

| 节点 | 揭示 |
|---|---|
| Node_1_2 断气 | 翠兰问高太公「你是谁呀」——读者第一次意识到她不对劲 |
| Node_1_4 望乡台 | 细看翠兰：眼睛是空的，连自己的名字都不应了 |
| Node_1_5 阎罗殿 | 崔判官：「生死簿上没有高翠兰这个名字」 |
| Node_1_7 忘川·春桃 | 她被灌了忘川水，活着喝的 |
| Node_2_4 夺簿 | 那一页被整页撕掉，只剩半边纸毛——「抹了」是撕，不是划 |
| Node_2_6 翠兰之谜 | 她是「民女为饵」的饵，戏眼，角儿 |
| Node_3_4 八戒 | 八戒找了她十四年，菩萨说「她很好，已经忘了」 |

## 线的尽头

翠兰从不出场于战场、地府、终局——她始终坐在高老庄的窗下看天。她的「不在场」就是暗线的本体：**被抹掉的人，连「出场」的资格都没有。**

两个结局给她两样东西：
- **焚簿**：她名字所在的那半边纸毛化作白蝴蝶，落在她窗台上——纸页里藏着的，是她的记忆；
- **认亲**：蝴蝶落进她手心时，她叫了一声「爹」——她没想起来，但她的记性，被父亲替着活了一辈子。

> **二周目看点**：注意全作对翠兰的称呼——从「翠兰」到「小姐」到「那个小姐」，称呼的退潮，就是名字被抹的过程。
