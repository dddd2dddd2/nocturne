# 暗线 03 · 八戒线

**一句话**：净坛使者是替神佛收拾剩饭的差事；他以为取经能保高家平安，取经本身就是高家的劫。

## 埋设节点

| 节点 | 揭示 |
|---|---|
| Node_1_1 喜报 | 「净坛使者，享受十方供品」——荣耀，但差事是「净」 |
| Node_1_5 阎罗殿 | 八戒的名字被金线划掉——超脱生死，也超脱了高老庄 |
| Node_1_7 春桃 | 他是观音拉进取经名单的「角儿」，入赘是剧本走位 |
| Node_3_4 净坛使者 | 他查过生死簿；他问过菩萨；他跪高太公；他哭 |
| Node_End_3 认亲 | 他脱了袈裟，扛着金钉耙回家种地 |

## 线的尽头

八戒是全书最「两头不是人」的角色：对天庭，他是净坛使者——收拾供品剩饭的；对高家，他是害了翠兰的猪头；对自己，他这辈子只信过两次，一次信菩萨，一次信高太公会认他这个女婿。
菩萨告诉他「她很好，已经忘了」——这句话是全书最温柔、也最残忍的台词：**他连「她忘了我」都无权知道，他只能知道「她忘了」。**

> **二周目看点**：第一幕里高太公骂「猪头」、想「好歹有个伴」的每一处，重读都是双刃——他对女婿的爱，和他对猪的恨，是同一句话。
