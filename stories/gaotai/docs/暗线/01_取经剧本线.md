# 暗线 01 · 取经剧本线

**一句话**：高老庄一难是观音写好的戏，高太公一家是布景；写书人从不认账。

## 埋设节点

| 节点 | 揭示 |
|---|---|
| Node_1_5 阎罗殿 | 「借与取经功果，以证高老庄一难」——阳寿借给的不是女婿，是「功果」 |
| Node_1_7 忘川·春桃 | 春桃亲口：菩萨借了猪、借了门楣、借了翠兰的身子，写了「强娶民女、降妖伏魔」的戏 |
| Node_2_6 翠兰之谜 | 剧本第一页：「第二十四难，高老庄收伏猪悟能」「此难需一民女为饵，事毕，将证物清干净」 |
| Node_3_6 佛光 | 观音亲口：「高老庄一难，本是我取经局中定好的一着」——写书人现身 |

## 线的尽头

取经八十一难，在佛门叫「磨砺」，在天庭叫「定数」，在阴间叫「功果折算」。同一件事，三种叫法，没有一种叫「杀人」。
高太公在佛光下问出的三个问题（女儿的名字谁抹的、丫鬟谁灭的口、阳寿谁借的），观音一个都没答——写书人不需要回答书里人的问题。

> **二周目看点**：重玩时带着「这全是戏」的眼光看第一幕，会发现连高太公请法师捉妖都是剧本走位——庄里人慌，是因为剧本写他们慌。
