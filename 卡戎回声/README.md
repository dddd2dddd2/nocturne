## 题材说明

本作选择 **赛博朋克深空科考站悬案**，因为它天然具备全部要求要素：

- **物理封闭**：深空、无对外通讯、补给遥远，逃无可逃；
- **时间倒计时**：轨道衰减 + 生命维持限时；
- **不可靠的AI**：舰载AI NORA 既是调查工具，也是布局者之一，构成天然的不确定叙述者；
- **双层反转的载体**："意识上传 / 被回声覆盖"这一科幻设定，让"表面真相 vs 隐藏真相"在逻辑上严丝合缝。
