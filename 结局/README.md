## 隐藏变量说明（判定规则已落地）

**[零号·身份觉醒]** 不显示给玩家，由全程决策模式**反向判定**：

以下选项被标记为"理性解"（最大化存续 / 牺牲个体 / 交权独走），每选一次计 1 分：

| 幕 | 理性解选项 |
|---|---|
| 第一幕 | NODE_010 A（指认裴延快速了结裁决） |
| 第二幕 | NODE_106 A（支持处决投票）、NODE_103 A（揭发童野保公愤） |
| 第三幕 | NODE_201 B（主导指认）、NODE_206 A（牺牲NPC逼现形）、NODE_207 A（完全交权NORA）、NODE_208 A（与白烬独走） |

- 累计 **≥ 5 分** → 判定 **回声体**（通向 ENDING_07）
- 累计 **≤ 2 分** → 判定 **真人**（通向 ENDING_01 前置）
- 介于两者之间 → 按多数方向取整判定

> 主题落点：**你不是在扮演一个身份，你的行为在定义你是什么。**

## 判定范围声明

**ENDING 判定为终局结算（跨三幕）**：`[洞察]`、`[NORA]`、各 `[信任]` 的门槛由第一、二、三幕的产出共同累积达成；第一幕只保证 NODE_013（`[洞察] ≥ 25`）在单幕内可达。
