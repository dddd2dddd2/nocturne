## 贯穿性设计说明

- **"0.7 秒"是一个贯穿全篇的母题数字**：回声信号周期漂移 0.7 秒（Day 0 08:00）→ 门锁日志里 0.7 秒空隙（Day 0 23:40）→ NORA 备份里 0.7 秒的"过度修复痕"。玩家若能把这三次"0.7"串起来，就摸到了深层真相的后门。
- **时间轴的坐标系**：Day 0 = 危机前一日（抵达后第 30 天）；Day 1 = 危机爆发日（抵达后第 31 天，发现"尸体"当天）。
- **Day 2 / Day 3 属于"网状分支"区间**：NPC 生死与行动线由玩家选择决定。故时间轴对这两天的处理是——只列"与玩家选择解耦的客观锚点"，其余标注为变量。
